# 푸른하늘 업무체험관

수도권대기환경청 네 개 과의 업무를 캐릭터로 걸어 다니며 체험하는 3D 웹 공간입니다. 체험을 하나 마칠 때마다 뿌연 하늘이 맑아집니다.

- 파일 하나(`index.html`)로 동작하는 정적 사이트입니다. 빌드 과정이 없습니다.
- 3D는 three.js 0.160.0(jsDelivr CDN)을 씁니다.

## 체험 내용

| 과 | 기본 체험 | 추가 체험 |
|---|---|---|
| 기획과 | 이동측정차량으로 VOC 배출원 찾기 | 푸른하늘 교실(어린이 질문에 답하기) |
| 대기총량과 | 비산배출시설 누출 점검 | 배출권 거래 관리 |
| 조사분석과 | 굴뚝 시료 채취·분석 | 측정소 자료 점검 |
| 자동차관리과 | 도로청소차로 재비산먼지 청소 + OX 퀴즈 | 연료 품질 검사 |

그 밖의 기능

- **하늘멍**: 잔디에 누워 하늘을 바라보며 쉬는 모드입니다. 호흡 안내와 1·3·5분 타이머가 있습니다. 시작 화면의 "하늘멍만 하기"로 바로 들어갈 수도 있습니다.
- **캐릭터 꾸미기**: 닉네임, 피부, 머리 모양·색, 옷, 소품(안경·마스크)을 바꿀 수 있습니다.
- **여럿이 함께**: 같은 방 링크(`?room=이름`)로 들어온 사람끼리 서로의 캐릭터가 보이고 채팅할 수 있습니다. 방 이름을 정하지 않으면 모두 `lobby` 방에 들어갑니다. 메뉴에서 방 링크를 복사하거나 새 방을 만들 수 있습니다.

## 조작

- PC: `W` `A` `S` `D`·방향키로 이동하고, `Shift`로 달립니다. `E`·`Space`로 대화·행동, `Enter`로 채팅, `Q`로 손 인사를 합니다.
- 모바일: 화면 왼쪽을 끌면 이동하고, 끝까지 밀면 달립니다. 오른쪽 버튼으로 대화·행동을 합니다.
- 직원이나 물건을 누르면 그 앞까지 걸어가서 바로 말을 겁니다.

## 알아 둘 점

- 측정값과 기준선 등은 **체험용 예시 값**입니다. 실제 수치나 절차와 다를 수 있습니다.
- 진행 기록(스탬프, 캐릭터)은 각자의 브라우저에만 저장됩니다.
- 여럿이 함께 모드는 시연용으로 **공개 MQTT 브로커**(`broker.emqx.io`, `broker.hivemq.com`)를 중계로 씁니다. 같은 방 이름을 아는 사람은 누구나 위치와 채팅을 볼 수 있으니 개인정보는 쓰지 마세요. 실제로 운영하려면 기관 전용 실시간 서버로 바꾸세요. `index.html`의 `BROKERS` 상수만 바꾸면 됩니다.
- 일부 기관망에서는 WebSocket(포트 8084/8884)이 막혀 여럿이 함께 모드가 연결되지 않을 수 있습니다. 혼자 체험은 그대로 됩니다.
